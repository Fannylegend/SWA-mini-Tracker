SWA MINI TRACKING WEBSITE - VERSION 1

Files:
- index.html: site layout
- styles.css: visual design and responsive styling
- script.js: interactive navigation, search and resource card rendering

OPEN LOCALLY:
1. Extract this folder if downloaded as a ZIP.
2. Double-click index.html to open in your browser.

PUBLISH WITH GITHUB PAGES:
1. Upload all three files (index.html, styles.css, script.js) to the ROOT of your repository.
2. Repository Settings > Pages > Deploy from branch > choose main and / (root).
3. Save and wait for publishing.

The site is a link dashboard and does not collect/store client or beneficiary records.
